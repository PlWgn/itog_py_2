# Блог

Итоговый проект по курсу «Фреймворк Flask».

Это веб-приложение для ведения блогов. Пользователи регистрируются, входят в систему и публикуют посты, а все посты видны на главной странице.

## Техническое задание

Нужно было:

- реализовать регистрацию новых пользователей, вход и выход из системы;
- хэшировать пароли с использованием Werkzeug;
- сделать форму регистрации с валидацией (e-mail, уникальное имя пользователя, надежный пароль);
- реализовать вход и выход пользователя с использованием Flask-Login;
- ограничить доступ к управлению постами только для авторизованных пользователей;
- реализовать создание, редактирование и удаление постов с валидацией данных;
- отображать все посты на главной странице с пагинацией и краткой информацией (заголовок, автор, дата публикации);
- создать страницу для просмотра полного текста поста;
- подготовить модели пользователей и постов на SQLAlchemy;
- реализовать миграции базы данных с использованием Flask-Migrate;
- использовать шаблоны Jinja2, оформить страницы с помощью CSS/Bootstrap и сделать навигацию.

## Что реализовано

- регистрация с проверкой данных: имя от 3 до 30 символов, корректный e-mail, пароль не короче 8 символов с буквами и цифрами, имя и e-mail не должны повторяться;
- пароли хранятся в базе только в виде хэша (`werkzeug.security`);
- вход и выход через Flask-Login;
- создавать посты могут только авторизованные пользователи, а редактировать и удалять пост может только его автор;
- проверка поста: заголовок не пустой и не длиннее 100 символов, текст не короче 10 символов;
- простое оформление на CSS и навигация по страницам;
- главная страница со списком постов по 5 штук на странице, новые посты сверху;
- страница поста с полным текстом;
- страница ошибки 404;
- база данных SQLite создается и обновляется по миграциям при запуске приложения.
